# 1HourMail

**1HourMail** — это веб-сервис **временной одноразовой почты**, созданный для защиты личных данных и борьбы со спамом. Сервис мгновенно предоставляет пользователю случайный email-адрес, который **активен ровно 1 час**, после чего безвозвратно удаляется вместе со всей историей сообщений.

Проект разработан как легкое, быстрое и полностью анонимное решение для повседневных задач в интернете.

---

## 💡 Решаемые задачи

* **Защита от спама:** Регистрация на подозрительных сайтах, форумах или блогах без риска захламить основной почтовый ящик.
* **Конфиденциальность:** Скачивание учебных материалов, книг или доступ к промокодам, которые требуют подтверждения email.
* **Безопасное тестирование:** Проверка отправки писем при разработке и тестировании собственного программного обеспечения.

---

## 🔥 Ключевые особенности

### 1️⃣ Абсолютная анонимность
Для получения почты не нужно вводить имя, пароль или привязывать номер телефона. Сервис не собирает логи и IP-адреса пользователей.

### 2️⃣ Автоматическое уничтожение
Таймер на 60 минут запускается в момент генерации адреса. По истечении часа все данные стираются из базы данных сервера. Восстановить доступ к старому ящику невозможно.

### 3️⃣ Работа в реальном времени
Письма приходят мгновенно благодаря технологии WebSockets. Страницу не нужно обновлять вручную — входящие сообщения появляются на экране сразу после отправки.

### 4️⃣ Поддержка вложений и HTML
Сервис корректно отображает форматированный текст писем (HTML), изображения, а также позволяет безопасно скачивать прикрепленные файлы.

---

## 🛠️ Как это работает (Пользовательский сценарий)

1. **Вход:** Пользователь открывает главную страницу сервиса.
2. **Генерация:** Система автоматически создает уникальный email (например, `user7392@1hourservice.com`).
3. **Использование:** Пользователь копирует адрес в один клик и указывает его на стороннем сайте.
4. **Получение:** Входящие письма мгновенно отображаются во встроенном веб-интерфейсе.
5. **Удаление:** Ровно через 1 час сессия закрывается, а адрес и письма стираются.
